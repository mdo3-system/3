# 🎬 Veo 3 動画制作マスター指示書 (5アカウント分散 投入シート)

Google Veo 3（Image-to-Video）に各アカウントから投入するためのプロンプト指示シートです。
- **1日のノルマ**: 5アカウント × 3クリップ = **1日15クリップ（5話分）**
- **重要原則**: 必ず各話の参照元画像（`images/vol1_*.png`）をVeo 3にアップロードした上でプロンプトを入力してください。
