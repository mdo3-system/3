# 📚 MDO3出版 公式ブランドアセット ＆ SNSプロフィール設定マニュアル

全SNSプラットフォーム（YouTube, 𝕏, Instagram, note）で統一された高品位なブランドアイデンティティを確立するための設定ガイドです。

---

## 🎨 1. ブランド素材（保存先: `sns_brand_assets/`）

| 素材 | ファイル名 | 推奨用途 |
| :--- | :--- | :--- |
| **公式アバターアイコン** | `sns_brand_assets/profile_icon.jpg` | YouTube / 𝕏 / Instagram / note のアイコン画像（円形トリミング対応） |
| **公式ヘッダーバナー** | `sns_brand_assets/channel_banner.jpg` | YouTubeチャンネルアート / 𝕏ヘッダー / noteカバー画像 |

---

## 🛠 2. 各プラットフォームの設定手順

### 🎬 ① YouTube チャンネル設定
1. [YouTube Studio](https://studio.youtube.com/) にアクセス
2. 左メニュー「**カスタマイズ**」→「**ブランディング**」タブを開く
3. **写真（アイコン）**: `sns_brand_assets/profile_icon.jpg` をアップロード
4. **バナー画像**: `sns_brand_assets/channel_banner.jpg` をアップロード
5. 「**基本情報**」タブを開き、以下を入力して「公開」をクリック：
   - **チャンネル名**: `MDO3出版`
   - **ハンドル**: `@mdo3_english`
   - **説明**:
     ```text
     英語古典（イソップ寓話、ことわざ、四書五経）× 英検多読で学ぶ大人の教養英語チャンネル「MDO3出版」です。

     発音に合わせて光るリアルタイム英語カラオケ字幕とネイティブ朗読で、シャドーイング・リスニング学習をサポートします。

     📚 Amazon Kindleストアにて電子書籍シリーズ好評配信中！
     ```

---

### 🐦 ② 𝕏 (旧Twitter) 設定
1. [𝕏 プロフィール設定](https://twitter.com/settings/profile) を開く
2. **アイコン画像**: `sns_brand_assets/profile_icon.jpg` を設定
3. **ヘッダー画像**: `sns_brand_assets/channel_banner.jpg` を設定
4. 以下の項目を入力して「保存」：
   - **名前（表示名）**: `上善如水出版`（または `MDO3出版`）
   - **ユーザー名**: `@mdo3_english`
   - **自己紹介 (Bio)**:
     ```text
     英語古典×英検多読の出版レーベル「上善如水出版（MDO3出版）」。イソップ寓話・ことわざ100・四書五経の英語朗読＆カラオケ字幕動画を毎日配信中📚 英語多読で自然と英検合格・リスニング力向上へ✨ Kindle Unlimited対応本多数配信中！
     ```
   - **Webサイト**: YouTubeチャンネルのURL または Kindle著者ページ

---

### 📸 ③ Instagram 設定
1. [Instagram プロフィール編集](https://www.instagram.com/accounts/edit/) を開く
2. **プロフィール写真**: `sns_brand_assets/profile_icon.jpg` を設定
3. 以下の項目を入力：
   - **名前**: `MDO3出版 ｜ 英語古典×英検多読`
   - **ユーザーネーム**: `mdo3_english`
   - **自己紹介**:
     ```text
     📖 英語古典（イソップ・ことわざ・四書五経）× 英検多読
     🎙 ネイティブ音声×カラオケ字幕で1分シャドーイング
     💡 英語を「読む・聴く・味わう」教養学習
     👇 YouTubeフル動画＆Kindle書籍はこちら
     ```
   - **リンク**: YouTubeチャンネルのURL

---

### 📝 ④ note 設定
1. [note アカウント設定](https://note.com/settings/profile) を開く
2. **プロフィール画像**: `sns_brand_assets/profile_icon.jpg` を設定
3. **ヘッダー画像**: `sns_brand_assets/channel_banner.jpg` を設定
4. 以下の項目を入力：
   - **クリエイター名**: `MDO3出版`
   - **note ID**: `mdo3_english`
   - **自己紹介**:
     ```text
     英語古典と英検多読を通じて「大人の教養」を育む教育レーベル「MDO3出版」の公式noteです。イソップ寓話、ことわざ100、四書五経などの名文をレベル別に解説し、動画・音声・単語表と連動した効率的な多読法をお届けします。
     ```
